1. What is Python?

   Answer: Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum. It is simple, readable, and widely used for web development, automation, data analysis, machine learning, and scripting.

   - Cross-platform compatibility
   - Strong community support
   - Good for rapid development

11. How does Python work internally?

    Answer: Python code is written in .py files and interpreted by the Python interpreter. The interpreter converts source code into bytecode, which is then executed by the Python Virtual Machine (PVM). This makes Python portable and easy to run across systems.

12. Explain Python architecture.

    Answer: Python architecture consists of:
    - Source code
    - Python compiler
    - Bytecode
    - Python Virtual Machine (PVM)
    - Standard library and built-in modules

    The source code is compiled into bytecode, and the PVM executes that bytecode. This architecture helps Python run consistently on different operating systems.

    Example:

    ```python
        print("Five is greater than three")
    ```

15. What are variables in Python, and how do they differ from other programming languages?

    Answer: Variables are named memory locations used to store values. In Python, variables are created automatically when assigned. Unlike languages like C++ and Java, Python does not require explicit type declaration.

    Example:
    ```python
    name = "Alice"
    age = 25
    ```

16. What are data types in Python, and how do they differ from other backend programming languages?

    Answer: Data types define the type of value stored in a variable. Python supports many built-in data types such as:
    - int
    - float
    - str
    - bool
    - list
    - tuple
    - set
    - dict

    Python is dynamically typed, so you do not declare types explicitly. In many backend languages, types must be declared before use.

17. What are functions in Python, and how do they differ from other backend programming languages?

    Answer: A function is a reusable block of code that performs a specific task. It helps reduce repetition and improve readability.

    Example:
    ```python
    def add(a, b):
        return a + b

    result = add(3, 5)
    print(result)
    ```

    Python functions are simpler and often shorter than functions in other backend languages because they do not require explicit type declarations in most cases.

18. What are the types of functions in Python? What are arguments and parameters in Python?

    Answer: Types of functions in Python include:
    - Built-in functions
    - User-defined functions
    - Anonymous functions (lambda)
    - Recursive functions
    - Higher-order functions

    Parameters are variables defined in the function declaration, while arguments are the actual values passed to the function when calling it.

    Example:
    ```python
    def greet(name, age):
        print(f"Hello {name}, age {age}")

    greet("Alice", 25)
    ```

    Here, name and age are parameters, and "Alice" and 25 are arguments.

19. What are the different types of arguments in Python?

    Answer: Python supports:
    - Positional arguments
    - Keyword arguments
    - Default arguments
    - *args for variable-length positional arguments
    - **kwargs for variable-length keyword arguments

    Example:
    ```python
    def show(name, age=18, *skills, **details):
        print(name, age, skills, details)

    show("John", 25, "Python", "SQL", city="Delhi")
    ```

20. What is the difference between list, tuple, set, and dictionary in Python?

    Answer:
    - List: ordered, mutable, allows duplicates
    - Tuple: ordered, immutable, allows duplicates
    - Set: unordered, unique values
    - Dictionary: key-value pairs

    Example:
    ```python
    my_list = [1, 2, 2, 3]
    my_tuple = (1, 2, 2, 3)
    my_set = {1, 2, 3}
    my_dict = {"name": "Alice", "age": 25}
    ```

21. What is the difference between Python and JavaScript?

22. What is the difference between Python and Java?

    Answer: Python is simpler and more concise, while Java is more structured and verbose. Java is often used in enterprise systems and large applications, while Python is preferred for rapid development and scripting.

23. What is OOP in Python?

    Answer: OOP stands for Object-Oriented Programming. It is a programming style based on classes and objects. Python supports inheritance, encapsulation, polymorphism, and abstraction.

    Example:
    ```python
    class Student:
        def __init__(self, name):
            self.name = name

    s1 = Student("Alice")
    print(s1.name)
    ```

24. What is the difference between a module and a package in Python?

    Answer: A module is a single .py file. A package is a directory that contains multiple modules and a package structure. Packages help organize code in a structured way.

25. What is the use of __init__ in Python classes?

    Answer: __init__ is a special method called automatically when an object is created. It initializes object attributes.

    Example:
    ```python
    class Car:
        def __init__(self, brand):
            self.brand = brand

    car = Car("Toyota")
    print(car.brand)
    ```

26. What is the difference between list comprehension and loop?

    Answer: List comprehension is a shorter way to create lists in Python, while loops are more explicit and easier for complex logic. List comprehension is concise but not always the best choice for complex conditions.

    Example:
    ```python
    squares = [x * x for x in range(5)]
    ```

27. What is the difference between deep copy and shallow copy?

    Answer: A shallow copy copies the top-level object only, while nested objects are still shared. A deep copy creates independent copies of the nested objects as well.

28. What is exception handling in Python?

    Answer: Exception handling is used to manage runtime errors without crashing the whole program. Python uses try, except, else, and finally blocks.

    Example:
    ```python
    try:
        x = 10 / 0
    except ZeroDivisionError:
        print("Cannot divide by zero")
    finally:
        print("This always executes")
    ```

29. What is a lambda function in Python?

    Answer: A lambda function is an anonymous one-line function defined using the lambda keyword.

    Example:
    ```python
    square = lambda x: x * x
    ```

36. What is the difference between a list and an array?

37. What are decorators in Python?

    Answer: Decorators are functions that modify the behavior of another function without changing its source code.

    Example:
    ```python
    def decorator_func(func):
        def wrapper():
            print("Before")
            func()
            print("After")
        return wrapper

    @decorator_func
    def hello():
        print("Hello")

    hello()
    ```

38. What is a generator in Python?

    Answer: A generator is a special iterator that yields values one at a time. It is useful for large sequences because it does not store all values in memory.
